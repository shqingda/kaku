# Android 正文多图闪烁修复候选

用户提供的 3.62 秒 Android 实机录屏显示：章节评论滚动时，多张正文图片出现短暂变淡和叠影，iOS 模拟器未复现。

复验位置：用户补充为《FX战士久留美》第一集第 6 条评论，重点来回滚动多张图片并检查 GIF 播放和点击预览。

正文图片原先统一使用 120 ms 淡入，加载后按原图比例调整高度。当前安装的 expo-image Android 实现会在尺寸变化时重新加载，并在两个原生图片视图间交叉淡入。针对该路径，仅将 Android 正文图片的 transition 设为 0；保留 GIF 播放、原图比例、点击预览和 iOS 的原有过渡。不升级依赖，不改正式版包名。

移动端类型检查和两项专项组件测试通过，覆盖 Android 三张图片加载后的独立比例与无淡入，以及 iOS 仍保留原过渡。组件模拟不能证明实机闪烁已消失，需在用户设备上用同一评论复验。

交付使用项目 `build-android.sh debug`：独立包名 `com.shqingda.kaku.debug`、debug 图标、arm64-v8a、自包含 JS，可与正式版共存且无需 Metro。这里的 debug 是项目的安装渠道，产物使用 Release 构建方式；不是需要连接开发服务器的开发客户端。本次基于 1.1.17 修复，未替换 GitHub 正式版安装包。

构建成功（1 分 25 秒），APK 52,933,494 B，版本 1.1.17 / versionCode 3。包名、签名及 16 KiB 对齐验证通过，安装包另存至 Downloads 的 `kaku-debug-1.1.17-image-fix.apk`。旧 debug 包若使用不同签名仍无法覆盖；本次沿用项目本地 debug 签名。
