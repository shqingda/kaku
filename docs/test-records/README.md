# 测试记录

按日期归档的手动测试与自动化测试记录，一份测试活动一个文件。

## 命名约定

```text
YYYY-MM-DD-<测试类型>-<版本或范围>.md
```

类型示例：`visual-test`（视觉测试）、`maestro-smoke`（maestro 冒烟）、
`release`（发版验证）。单元测试不单独立档——结果看 `pnpm test` 输出即可。

## 每份记录的固定结构

1. 引言块：日期、环境（设备/系统/主题/登录态）、被测版本、方式
2. 范围：测什么
3. 检查项与结果（表格）
4. 发现的问题与修复
5. 证据位置（截图目录、run 产物、flow 文件）
