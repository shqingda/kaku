## 遇到的问题

- 首次构建失败：后台 shell 不加载 `.zshrc` 里的 `ANDROID_HOME`/`JAVA_HOME`，
  gradle 报「SDK location not found」。显式 export
  `ANDROID_HOME=~/Library/Android/sdk` 与 Zulu 17 后一次通过。
  备选改进：在 `scripts/build-split-apks.sh` 开头加 `ANDROID_HOME` 兜底默认值。
