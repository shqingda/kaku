- 这是源文件去重，不能宣称 APK 同等缩小。最近发行 APK v1.1.22 为 44,480,063 字节；单 ABI、R8 和资源裁剪此前已启用，见 [发布记录](2026-10-24-release-1.1.22.md)。本轮没有新的发行包体对比。
- 新增只读命令 `node scripts/report-workspace-files.mjs`：固定白名单，仅统计逻辑文件字节；不读取文件内容，不跟随符号链接，不接受删除参数。排除 tutorial、签名、环境配置、安装包、全部模拟器数据；原生源工程和本地 API 数据不列作可清产物。
- 一次白名单快照为源码 5,702,285、开发产物 2,327,595、依赖 2,953,316,197 字节。采样早于最终文档归档；依赖硬链接可能重复计数，不代表物理占用或可释放空间。本轮没有批量删除开发产物。
- 依赖按入口、原生链接、配置插件和 peer 核对后，未发现可证明无用的生产依赖。`expo-dev-client`、`expo-system-ui`、`expo-linking`、`react-dom`、`react-native-screens`、`react-native-worklets` 虽部分缺少直接 import，仍有原生/插件/peer 用途，保留。node-forge 与 drizzle-kit/esbuild 的 2026-10-31 复核仍在 TODO。

## 当前设备证据与测量边界

使用前列出设备，仅复用 iPhone 18 Pro / iOS 27.0（`498E27B7-5192-48CE-9B13-F4A27F10F806`）；PosterBoard 保持禁用。`pnpm dev:sim` 复用现有客户端与数据，预览 `http://localhost:3200/`。没有创建/抹除设备、卸载、退出账号或清空历史/草稿。需要新游客环境的流程未执行。

- 用户自行重新登录后，预览确认首页显示好友动态；设置页外观、搜索历史与浏览历史均收敛为“已同步”。未切换同步开关或制造远端数据。
- 通过预览实际点击完成菜单、设置和首页返回。中文搜索输入未在预览中得到可确认的结果，本次不算通过；未发送内容，不用粘贴冒充中文组合输入验收。
- 现有开发客户端安装信息为 1.1.21 / build 1（当前 JS 来自 Metro）；只读逻辑文件大小：app bundle 162,291,755、应用数据 50,671,247、其中 cache 29,939,741 字节。数据包含此前使用状态，不能与正式包或首次安装比较，也不相加重复计算 cache。
- `argent` 不可用；Xcode Activity Monitor 按应用名无法附加，按 PID 附加返回 “Activity monitoring service not available on this device”。React Native 调试连接返回 HTTP 401，未绕过认证。可靠的 JS heap、原生/图片内存拆分、Query 数量和慢帧采样未取得。
- 因而尚未建立当前设备三轮完整路径基线，不报告启动、内存或帧率改善百分比，不与旧 iPhone 17 Pro / iOS 26.5 数据比较。以后进程冷启动必须注明“保留现有数据”，不能称首次安装。
