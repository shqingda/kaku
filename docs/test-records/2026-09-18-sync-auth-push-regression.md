## 已修复

- 搜索历史、最近浏览共用同步调度；本地缓存按账号隔离。旧请求和排队写入在账号切换、关闭同步、卸载时失效。
- 主题写入串行执行，旧响应不能覆盖新编辑，云端响应不能改变本机同步开关；初始化完成前不访问偏好云接口。
- 迟到的 401 复用已轮换凭据；旧刷新结果不能覆盖或清除新登录。仅明确的重新授权错误码触发 409 登出。
- 注销推送携带设备 token，后端校验用户归属，只删除该设备。新设备只初始化自己的游标，其他设备照常收取待发送通知。
- 推送先恢复本机开关，再登记或注销；操作串行执行，注销失败明确提示并支持重试。
- Kaku 认证请求的外部取消和 12 秒超时同时生效，避免同步队列永久阻塞。

## 升级与发布边界

- 本轮未推送、部署 API 或发布安装包；无数据库 schema 迁移。
- 应先部署 API，再发布客户端。旧客户端不带 token 的注销请求返回 400，不再执行用户级删除；客户端需要升级才能使用精确注销。
- 新版把历史写到按账号隔离的 v2 缓存。旧全局缓存没有可靠账号归属，保留原值但不自动导入；登录并允许同步后从云端恢复。仅保存在旧设备、从未同步的历史不会自动出现在新版列表。
- 旧版本未持久化推送 token 时，新版尝试从已授权原生通知模块恢复；无法获取 token 时不会退回用户级删除。
- 本轮没有真机验收。双账号、双设备推送、旧安装升级、系统通知权限与离线恢复仍须补验，见根目录 TODO。
