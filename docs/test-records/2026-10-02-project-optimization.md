### 依赖与资源证据

Gradle 的 releaseRuntimeClasspath 指向 `expo.modules.camera:57.0.6 → ML Kit barcode-scanning`。虽然旧插件写了 `barcodeScannerEnabled: false`，当前预编译原生模块仍引入扫码库。业务源码没有调用 CameraView / expo-camera；开发客户端自有扫码实现不依赖 ExpoCamera，因此保留 expo-dev-client，删除产品未用的相机模块。

删除后，iOS clean prebuild + 开发客户端编译/安装成功；Android 默认与裁剪包均不再含 `libbarhopper_v3.so` 和 ML Kit 条码模型，iOS Pod 与 Android 自动链接中没有 ExpoCamera。开发客户端连接能力通过模拟器回归验证，真实摄像头扫码仍需设备。

三份 `app-icons/legacy` 与现有原稿完全相同，删除共 **1,491,333 字节仓库文件**。这些归档不在打包引用链中，APK 收益记为 **0**。原稿保留，因为启动屏、通知图标和图标生成器仍使用；light/dark 图标虽相同，但配置各自引用，保留。
