# v1.1.26 发布记录

## 源码与变更

- 版本 1.1.26 / Android versionCode 13。
- 发布动态改用可见的安全验证卡片，可取消并保留草稿；修复发布按钮卡住，键盘打开时点一下即可发布。
- 好友动态合并显示自己的动态，修复启动后刷新一直失败的问题。
- 新应用图标，设置 → 外观 → 应用图标可切换三种样式。
- 多个列表在网络暂停或读取失败时保留已有内容并明确提示；图片失败可单独重试。
