途中修掉的三个回归（都是本轮引入、已被用户或测试抓住，新会话引以为鉴）：
- 发现区排版崩坏：reanimated 的 `createAnimatedComponent` **会丢弃 Pressable 的函数式 style**，`PressableScale` 现在自己解算函数式 style 再传纯数组。
- 重试按钮可见文案变成读屏长句：`AppState` 新增 `actionAccessibilityLabel` 分离可见文字与读屏标签。
- 条目页骨架位移：骨架必须渲染在与真实页**同一个 ScrollView + contentContainerStyle** 里，否则安全区差异导致整页跳动。

## 必须知道的坑（新增约定）

- **测试双轨**：`tests/*.test.mjs` 归 node:test（被测模块整条导入链不得含 react/react-native/expo，导入必须带 `.ts` 扩展名）；`tests/*.test.tsx` 归 jest（`@/` 别名可用）。两套 testMatch 互不重叠。
- **RNTL v14**：`render`/`rerender` 都是 async，必须 await；用 render 返回的 queries，别 import `screen`。
- **jest 里别引 reanimated**：组件若 import reanimated 会在 jest 导入期崩溃（未配 mock）。AppState 的淡入为此改用 RN 自带 Animated。要测 reanimated 组件需先在 tests/ui/setup.ts 配 mock。
- **node 可测性**：`src/lib/user-error-message.ts`、`src/features/emoji-picker/emoji-catalog.ts` 已改为相对导入；新写 lib/feature 纯模块若想进 node 测试，内部导入用相对路径 + `.ts` 扩展名。
- **4 个 kaku 客户端的 `.ts` 扩展名已修**（preferences/config/recent-subjects/search-history），新的客户端文件记得照做。
- push 前清代理环境变量（AGENTS.md 老规矩）。

## 调研发现、尚未处理的问题（按优先级）

1. **AppSheet 兜底路径潜在 bug**（`features/shared/app-sheet.tsx:177` 附近）：withDecay 兜底 `withSpring(windowHeight)` 分支**没有回调 onClose**，投影临界时可能滑到底却不关闭。viewer 的对应实现已带回调，可照抄。
2. **query-keys 用户名规范化不一致**（`src/lib/query-keys.ts`）：`publicUserEntities` trim+小写，其余 publicUser* 原样。同一用户混合大小写会裂出两份缓存。修的时候要连缓存 buster 一起评估。
3. **auth-redirect 循环防护只精确匹配** `/account`，带查询参数的路径可绕过（低危边缘案例）。
4. **cached-data-notice 未加 iOS 播报**（footer 和 AppState 已加 announce；信息类提示可保持安静，属可选项）。
5. **组件测试覆盖仍薄**：41 个只是首批（AppState/PagedListFooter/footer/connectivity/reduce-motion/header 按钮/invalid-route + usePagedList 10 个）。PressableScale、Skeleton、AppSheet、17 个分页屏的行组件、`use-catalog-subject`（需 query mock）都还没测。
