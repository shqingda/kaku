## 关键设计

- 偏好内部增加 localStatus/localError/retryLocal/canSync。存储不存在才用默认值；读/解析/结构错误保留原数据并暂停同步。恢复合并用户实际编辑字段，不能把临时默认值落盘。关闭同步立即取消；开启须保存成功。偏好、搜索、浏览及历史清除确认统一使用可靠门禁；同步作用域独立检查代次，防止同一渲染批次内切换开关后旧确认继续执行。云重试等待对应本机写入成功并确认版本。存储键/格式不变，旧重试不得覆盖新修改。
- 公共缓存 match 失败视为未命中，put 用 Worker waitUntil 持有且捕获错误；不吞上游、鉴权或限流失败。无 Worker 执行上下文的调用须有明确等待路径，保留规范化缓存键及 HIT/MISS。
- 图片退出采用带符号速度投影；弹层重新定向从显示值继续，旧回调不能卸载新打开的内容。worklet 只能调用模块级 worklet 或内联代码。TYPE/SPACING 迁移覆盖所触及屏幕。
- 图片只清理自己创建的临时文件；相册保存成功后的清理失败只记录诊断。APK 记录目标版本与大小，后续启动确认本机安装版本不低于目标、文件大小与记录一致才自动清理；未知旧文件留给显式清缓存。活动下载/安装不被清缓存打断，安装器返回不代表安装成功。
- 旧推送 receipt 只删除已退出生产的写入/查询方法。FCM/APNs 的接受结果 tickets 仍决定哪些设备推进游标，必须保留；历史表、过期/会话清理、旧登记兼容和原子提交不删。
- shared 只承接已证实相同的合同，字段、可空性、默认值、校验和 HTTP 协议不变。资源去重保持生成过程和外观；源码减少不当作安装包收益。
- 发布准备、构建和上传分开，移除隐式 commit/push；复用已经验证的 APK，按现行草稿/curl流程核对远端大小与 SHA-256。白名单开发产物工具只读盘点，不处理 tutorial、签名、环境文件、已验证 APK 或模拟器数据。
- 发行构建归档 APK SHA-256、版本、Git 提交及工作区状态，并核对 APK 内 bundle 与同次 Gradle 产物一致后归档 source map；仅本轮启用 R8 时收录 mapping。缺失文件如实记录，历史 APK 不用重新导出的 map 冒充匹配记录；真实 Sentry 上报仍按设备与凭据条件验收。

## 性能实验协议

最新已发布 APK 为 44,480,063 字节，单 ABI、R8、资源裁剪已经完成。仓库、开发目录、APK、安装后占用和应用缓存分别统计。

同设备、源码配置、构建模式、缓存状态和操作路径至少采三轮。保留数据的进程冷启动不冒充首次安装启动；开发模式不冒充 Release。旧 iPhone 17 Pro / iOS 26.5 基线不能直接用于当前设备。

启动区分进程启动、JS 首布局、缓存水合与首页有意义结果；内存区分 Query 数/页数、JS heap、原生及图片内存。路径覆盖首页→搜索→条目→长章节→角色→返回、多图长帖→缩放/关闭、长列表返回、中文长文本输入。

章节分页并发固定为 3，取消后不启新页，保留完整章节和顺序；不能以截断、吞页失败或不完整离线包提速。资料/章节分离和关闭态查看器按需初始化分别实验；后者须保留退出动画、重开及已开始的保存操作。

既有 24h 持久化、100 queries、2 MiB、分页快照两页、10 个/30 天离线包先保留。不全局 maxPages，不直接缩短 gcTime；[TanStack 文档](https://tanstack.com/query/latest/docs/framework/react/plugins/persistQueryClient) 要求与 maxAge 协调。按采样优化热点，不批量 memo 或换列表库，不防抖草稿而降低可靠性。

每次只改一个主要因素。功能正确且收益超过同批采样波动才保留新增复杂度，否则撤回并记原因。缺可靠 profiler 的指标保持待验；毫秒、字节和内存指标不混入同一量纲检查器。
