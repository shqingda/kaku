## 接口、依赖与保护边界

- M3 不新增接口、不迁移 D1、不改变有效响应格式或时间戳含义；仅将损坏存储从成功空值改为明确失败。日志不输出历史正文，读取失败不得触发修复性清空或自动写回。
- M5 不删除后台离线保存/读取/清缓存、诊断记录及脱敏。框架约定导出、数据库 schema、迁移和仍被生产内部调用的测试专用导出不能仅凭引用报告删除。
- M9 只调整模块归属与共享基础定义，不改变协议字段、可空性、存储键、缓存版本或合法旧数据兼容；BBCode、引用与图片输出维持现有行为，不引入 Provider 注册框架。
- 依赖不跨 major，手机端遵守 Expo SDK 58 配套矩阵。实施时复核官网 React/react-dom 19.3.1 与 Workers types 5.20261031.1 的发布时间，满 24 小时才升级；未满则保留当前版本并记录，不能自行豁免。
- 显式设置 `minimumReleaseAge: 1440` 与内置豁免的 `prune` 策略，移除已无效的旧精确豁免；复核 node-forge 官方修复、本地补丁及其他 override 的真实依赖路径。官网 Vite/plugin 和仅类型使用的 shared 调整到 devDependencies，保留有运行、测试或原生配置用途的 miniflare、test-renderer 等依赖。
- 动效从当前屏幕值续接，继承速度、投影动量且随时可打断；可触控交互优先弹簧，按下立即反馈。UI runtime 回调只调用模块级 worklet 或内联代码。字号与间距使用 TYPE/SPACING，触及屏幕顺带迁移旧裸值。
- 认证、草稿、历史、账号隔离、未知写入占用、请求取消与旧客户端保护继续保留。未经用户新授权不恢复已撤回功能，不重启无收益实验；既有设备、账号、上游、商店及兼容跟踪事项全部接续到 TODO。
- `tutorial/` 不改动、移动、重命名或删除，不计入瘦身目标；提交前独立核对文件清单和内容摘要。历史记录仅在确认重复且没有独有证据时才可整理，本轮先保留原记录并更正现行入口。

## 验收与交付约定

每片运行与改动相关的类型检查和行为测试；文档片只检查事实、链接与差异。阶段整合执行一次完整 `pnpm ci:check`，输入未变且已通过的检查不机械重跑；新修改、失败或未解决风险再补对应验证。API 75% / mobile 92% 行覆盖门槛不降低，不能为清理测试删除仍有保护价值的断言。

关键验收路径：

- 云历史：无记录、正常空数组、合法旧数组、损坏 JSON、非数组、非法项；失败不修改 D1、不覆盖本机，恢复后可重试。
- 清理与重构：并发离线保存/清缓存、保存失败不覆盖；收藏保存/清空确认/外链失败；正文解析差分与跨端定义兼容。
- 列表与图片：首次离线、刷新与分页失败、恢复联网；图像失败重试、换图后的迟到回调、关闭重开、缩放和关闭可中断。
- 阅读：短文、真实超行长文、宽度变化、大字体、动画反向；页脚状态播报无重复。模拟器验证不代替实际 VoiceOver。
- 工具链：冻结安装、Expo 配套检查、受影响测试及类型、JS 导出与官网构建；复核真实依赖路径，记录兼容问题和未更新原因。

iOS 先列出设备，仅使用 iPhone 18 Pro / iOS 27.0（`A395E274-D899-42DA-BE4C-416A9F89F671`）；不新建、克隆、抹除、卸载、退出或清数据，PosterBoard 保持禁用。下次启动提醒用户重新登录，由用户完成。需要新游客环境、持久草稿、真实发送或破坏性清理的路径跳过并报告。模拟器启动与允许的输入恢复按 [模拟器指南](../development/ios-simulator.md) 和 [Argent 指南](../development/argent-usage.md)。
